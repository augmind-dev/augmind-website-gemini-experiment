A status shown three ways at once: an icon, a word and a colour.

Some readers are red-green colour blind, so a status is never colour alone. Classes `.tag .tag-scale` (keep spending, up arrow), `.tag-audit` (check this, warning triangle), `.tag-keep` (leave as is, equals bars). The "not named" line (`.miss`) uses `no` text with a cross icon.

You provide: the word. Pick the class by meaning; the icon comes with it.

Don't: invent a fourth colour, or drop the icon to save space.

The warning tag (`.tag-audit`) also has a 1.5px outline in its own colour. Its pale red fill and the pale green of the "scale" tag are the same colour to a red-green colour-blind reader, so the outline makes the shape differ as well.
